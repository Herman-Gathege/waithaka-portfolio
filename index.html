01 Introduction

I engineer the parts of a product people feel rather than notice: a layout that holds together on any screen, a page that loads before patience runs out, a flow that asks for exactly what it needs.

  • Responsive and adaptive, mobile-first interfaces
  • Accessible components and semantic markup
  • Performance budgets, Core Web Vitals and SEO
  • Peer code review and change control

I’m a front-end engineer with 3+ years of experience building responsive, cross-browser compatible web and mobile-web applications with JavaScript, TypeScript, React.js and Vue.js. I work inside agile teams, ship through Git-based CI/CD, and treat application security as part of the build rather than an afterthought.

My work usually starts where a design hands off and ends when someone can complete a task without friction — consuming RESTful APIs to display data, validate input and post updates, managing state with Redux Toolkit and Pinia, and tuning SEO-focused single-page applications.

AlphaOne

A full-stack SaaS platform for property managers, built collaboratively across the stack: a React and Vite front end paired with a FastAPI and PostgreSQL back end, containerised with Docker Compose.

I designed responsive dashboards for organizations, properties, units, tenants, leases, billing, payments and finance analytics, and implemented JWT authentication with protected routes and role-based access control. Security hardening covered rate limiting, PII encryption and HMAC-SHA256 blind indexes, and the platform integrates the WhatsApp Cloud API for tenant notifications, payment reconciliation and automated messaging workflows.
