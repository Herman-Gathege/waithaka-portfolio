01

Overview

OnQ Global runs corporate websites that carry both brand and demand. As Digital Experience Specialist I develop and improve the user-facing features on those sites — new pages, layouts and the continuous refinements that keep them aligned with marketing objectives.

Because the same team owns the site’s visibility, the role spans implementation and measurement: shipping the change, then reading the analytics and search data to decide what changes next.

02

What the work involves

  • Developing and improving user-facing features across corporate websites using HTML, CSS, JavaScript and React — contributing new pages, layouts and continuous refinements aligned with marketing objectives.
  • Implementing UI/UX and search analytics through Google Analytics 4, Google Tag Manager, Google Site Kit and Google Search Console, and turning the results into improvement decisions.
  • Executing on-page SEO — metadata, internal linking, schema markup and keyword tracking — to strengthen discoverability and performance.
  • Liaising with software vendors and third-party partners to document, escalate and resolve platform and integration issues efficiently.
  • Following change control procedures in Git-based deployments, and seeing website initiatives from conception through release.
  • Championing user-centred design through UI development best practices, user feedback and continuous optimisation of experience and performance.

03

Approach

  • Start from the page that has to change: a new layout or section is built as a reusable pattern so the next request is faster than the last.
  • Ship through change control: Git-based deployments with review means a marketing deadline never has to mean an unreviewed release.
  • Instrument before you argue: GA4, Tag Manager, Site Kit and Search Console data settle questions about which pages, terms and journeys deserve the next sprint.
  • Structure for search: metadata, internal linking and JSON-LD schema markup are part of the build, not a later audit.
  • Escalate cleanly: documenting third-party and platform issues with enough detail that vendors can act is part of keeping the site reliable.

04

Tools

HTML5 CSS3 JavaScript React Google Analytics 4 Google Tag Manager Google Site Kit Google Search Console JSON-LD schema Git-based deployments

05

Where it stands

The role is current, and the work is continuous rather than a single launch — pages, refinements, SEO and analytics run side by side with the marketing calendar.

Because these are OnQ Global’s own platforms, I do not publish their traffic, rankings or conversion data here. The scope of the role is described in full, and the techniques involved transfer directly to any content-led site.

06

Key takeaways

  • Working close to marketing changes what “done” means: a page is finished when it is discoverable and measurable, not only when it renders correctly.
  • Analytics is most useful when it arrives before the decision, which is why the tracking work happens alongside the feature work.
  • Reliable escalation with vendors is a real engineering skill — the quality of the report usually decides how quickly the issue is fixed.
